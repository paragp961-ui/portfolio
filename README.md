# Parag Patil — Four-page creative portfolio

A responsive static portfolio with four pages:
- `index.html` — Me
- `work.html` — Work and campaign concepts
- `poet-on-edge.html` — Poetry / afterword page, ready for future writing
- `contact.html` — contact details placeholders to replace before publishing

## Upload to GitHub Pages
1. Keep a backup of your existing repository first.
2. Upload the four HTML pages, `style.css`, and the `images/` folder to the root of the existing `portfolio` repository.
3. Keep `script.js` if you already have it; this redesign does not depend on it.
4. Replace `YOUR_EMAIL@example.com`, `+91 XXXXX XXXXX`, and the generic LinkedIn URL in `contact.html` with your real public contact details.
5. Check that all images are in the `images/` folder and filenames match exactly (lowercase).
6. Commit changes to the branch configured for GitHub Pages and wait for deployment.

The Office reaction image on the Me page is the image provided by the site owner. Confirm you have the rights to publish it publicly. Campaigns are labelled as speculative concepts; do not present them as commissioned client work unless that is accurate.
