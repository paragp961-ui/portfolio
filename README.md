# Parag Patil — Copywriting Portfolio

A responsive, animated starter portfolio built with plain HTML, CSS and JavaScript. No paid framework or build step is required.

## Before publishing

1. Open `index.html` in a text editor.
2. Replace `YOUR_EMAIL@example.com` with your real email address in the `mailto:` link.
3. Replace the LinkedIn link with your own profile URL.
4. Edit the About section so it accurately reflects your experience.
5. Replace the four starter concepts with your own work, or keep them clearly labelled as speculative concepts. Do not present sample concepts as work completed for real clients.
6. Update the page title and description if needed.

## Preview locally

Double-click `index.html` to open it in a browser. The layout is responsive and uses CSS-made artwork and motion effects, so no image files are required to preview it. Google Fonts load from the internet; fallback fonts are included.

## Publish for free with GitHub Pages

1. Create or sign in to a GitHub account at https://github.com/.
2. Create a **public** repository. For a personal site, a repository named `YOUR-USERNAME.github.io` is convenient; alternatively, use a repository named `portfolio`.
3. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository's root folder.
4. Open the repository's **Settings**.
5. Select **Pages** in the sidebar.
6. Under the build/deployment section, choose **Deploy from a branch**.
7. Select the `main` branch and the `/ (root)` folder, then click **Save**.
8. Wait for deployment and open the URL GitHub Pages shows you. A personal repository typically publishes at `https://YOUR-USERNAME.github.io/`; a project repository typically publishes at `https://YOUR-USERNAME.github.io/portfolio/`.

GitHub may take a few minutes to publish changes. Hosting a public static portfolio this way is free under GitHub Pages' applicable usage limits. A custom domain is optional and usually costs extra.

## Add real GIFs or images

Create an `images` folder in your repository and upload your files there. In `index.html`, you can place an image inside a project visual, for example:

`<img src="images/my-campaign.gif" alt="Animated campaign concept">`

For a cleaner design, use appropriately sized, compressed images. GIFs can be large; short MP4/WebM clips are often smaller and smoother, but browser autoplay rules apply. Keep the case-study description accessible as text as well.
